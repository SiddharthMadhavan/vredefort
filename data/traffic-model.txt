CityCollapse: synthetic hourly traffic and conditional closure assignment

INPUTS AND UNITS
The supplied CSV is synthetic, with one record per KML graph edge per hour.
Assume Traffic Volume is vehicles/hour, total both directions, Average Speed
is km/h, and congestion/utilization are percentages. Timestamps are assumed
local Asia/Kolkata. These units are assumptions because the file has no units.
All 4,448 IDs match exactly; all 168 hours have complete coverage.

CAPACITY
For each edge, C_e = median_h[q_e,h / (u_e,h / 100)], using only hours with
u < 95%. Utilization is capped at 100 in the CSV, so saturated hours cannot
reliably infer capacity. Capacities are estimates from synthetic values, not
surveyed lanes or physical road widths (KML width units are unspecified).

BASELINE
b_e(h) = CSV flow. Observed travel time t_obs = length_m / (speed_kmh / 3.6).
With no closures, flow, speed and congestion reproduce the CSV. Hours are
piecewise constant; playback speed changes the clock, not traffic volume.

CLOSURE DEMAND (NO OD OR TURNING DATA ARE PROVIDED)
A blocked road has zero capacity and is excluded from routing. Its baseline
flow becomes a local trip demand between its two endpoint nodes. This assumes
the affected trips must reconnect those endpoints; unaffected traffic remains
fixed. This is a conditional incident scenario, not global OD reconstruction.
For a closed self-loop road, both graph endpoints are the same junction and
the local trip destination on that loop is unknown. Report its baseline flow
as unmet; do not erase its demand through a zero-length endpoint route.

A blocked junction removes all incident edges. Adjacent blocked junctions are
grouped into one cluster to avoid counting their internal link traversals as
new trips. Aggregate boundary loads b_i by surviving neighbouring node.
For k boundary neighbours, assume symmetric local turning demand
  d_ij = min(b_i, b_j) / (k - 1), for i < j and k > 1.
Each approach uses at most its baseline flow. Total trip demand at a cluster
is sum_i(b_i)/2 because a through trip traverses two boundary edges.
The difference between that and sum_ij(d_ij) is unmet endpoint demand.
For a single boundary neighbour, all demand is unmet. This conservative
turning assumption is explicit; turning counts would allow replacing it.
Explicit road closures touching a blocked node belong to the node scenario
and are not counted again. Junction closures are not simple road detours.

CONGESTION-DEPENDENT ROUTING
Let r_e be assigned detour flow; on an open edge q_e = b_e + r_e.
Travel cost is the baseline-anchored BPR volume-delay function:
  t_e(q) = t_obs,e * [1 + 0.15*(q/C_e)^4] / [1 + 0.15*(b_e/C_e)^4].
This preserves measured synthetic speed at baseline while increasing travel
cost on overloaded detours. Shortest paths use travel time, not random turns.
Parallel graph edges retain their own IDs. All routing is undirected.

Assign affected demand to shortest paths, then iterate the method of
successive averages (MSA): r_(n+1) = r_n + (a_n - r_n)/(n+1), where a_n is
the current shortest-path all-or-nothing assignment. Stop at relative gap
<= 1% or 60 iterations. The reported gap is computed on the returned flows:
  gap = [sum_e(r_e*t_e) - sum_OD(d_OD*shortest_cost_OD)] / sum_e(r_e*t_e).
This measures convergence for affected demand with fixed background traffic.
If the iteration limit is reached, the UI labels the result approximate.
No-path demand is reported separately in vehicles/hour, never silently lost.
Affected demand = rerouted demand + unmet demand. Detour link-flow totals
need not equal trip demand because each trip traverses multiple road edges.

VISUALIZATION
Green -> yellow -> red shows congestion. The baseline congestion fraction g
is adjusted by travel-time ratio R=t/t_obs:
  g_new = clamp(1 - (1-g)/max(1,R), 0, 1).
Glow grows with congestion. Light trails move continuously along road curves;
busy roads have denser trails. Native Canvas lines animate independently of
model calculations and map image loading. State changes fade smoothly while
the previous display remains visible. Play/Pause controls the clock and flow.
Trails are visual cues, not vehicles or measurements of directional traffic.
Motion is limited on short/offscreen roads and has a viewport budget for speed.
Closure mode highlights every closed edge and every edge with numerically
positive added assigned flow (tolerance max(1e-6 veh/h, baseline*1e-9)).
Affected junction markers are endpoints of these edges, not simulated signal
or junction failures. Lists are paginated, with every affected item accessible.

DIVERSION PREVIEWS
MSA path allocations are retained and exactly reconstruct detour link flows.
For an explicitly blocked road, Yen's algorithm offers up to three shortest
loopless endpoint-to-endpoint routes under the final scenario travel costs.
Every preview avoids all currently blocked roads and junctions. Route travel
time is the sum of current scenario edge travel times; it is not the forecast
after all drivers switch to that preview. Selecting a route changes only the
map highlight, not the traffic assignment. Junction closures show the actual
approach-to-approach paths and flow used by MSA. No feasible path is reported
explicitly, including unknown self-loop trip destinations and blocked endpoints.

INFRASTRUCTURE FLAGS
Only the existing mapped hospitals and fire stations are assessed. A facility
within 250m of a blocked or diversion-loaded polyline is flagged for potential
access delay using a local Web Mercator distance corrected for latitude.
This proximity flag does not establish loss of access, an outage, response
time, or service failure. All nearby affected edge IDs and the nearest distance
are retained. Original coordinate provenance and inferred hospital matches
remain visible. Unmapped hospitals and assets without data cannot be assessed.
Blocked edges are muted with red crosses; blocked junctions are red squares.
Road details include baseline flow, scenario flow, estimated capacity, speed,
congestion and closure state. All scenario results remain labelled synthetic.

LIMITATIONS
This is quasi-static hourly replay with incident reassignment, not a dynamic
traffic assignment solver: no queues, finite storage, signal timing, one-way
rules, spillback, destination choice, trip cancellation or live traffic.
Network topology is inferred from exact shared KML vertices; some physical
crossings are disconnected, and bridge/turn restrictions are not available.
Real predictions require measured OD/turning data, surveyed capacity,
validated topology and calibration. Blocked-node demand is an assumption.
